# 地图绘图 Skill

用于有标准行政区编码的地域分布；没有 GeoJSON 或标准边界数据时不得伪造地图形状。

先读取 [通用图表规则](common-rules.md)：统一处理来源、筛选、快照、分母和小样本说明。

输出要求：

- 使用 `<figure data-chart-skill="map-chart" data-chart-id="CH1">`。
- 只有在具备标准行政区编码和可用边界数据时绘制内联 SVG 地图；否则输出“未评估”及缺失原因。
- 包含图例、单位、地域口径、来源、快照日期、`<title>` 和 `<desc>`。
- 不使用外部地图脚本、远程瓦片或截图冒充数据地图。
